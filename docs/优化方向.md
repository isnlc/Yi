# 后续优化方向

> 本文件记录当前实现尚未覆盖的范围。

## 1. 真实长期数据

现有主数据为 219 条模拟个人记录，另有 3 段拟真自然笔记回放。后续需要使用经过脱敏的真实跨月记录，检查口语省略、错误日期、多人信息混入和跨主题叙事。

## 2. 开放式回答评价

当前主实验采用关键词和拒答规则，便于稳定复现，但不能完整评价表达质量。后续可增加人工双盲评分或独立模型裁判，并保留现有确定性指标。

## 3. 长窗口呈现

日历窗口已经全量召回；当查询跨度达到半年或一年时，回答仍可能过长。可在不改变证据集合的前提下，增加按主题聚类、阶段摘要和可展开时间线。

## 4. 多用户与权限

当前产品按单用户本地数据设计。多用户部署需要增加身份隔离、附件访问权限、加密存储、审计留存周期和删除策略。

## 5. 性能与部署

当前规模以课程项目和个人使用为目标。更大数据量下应测量索引构建时间、查询延迟、附件解析成本和并发写入，并考虑持久化数据库与增量索引。
